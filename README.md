# CountChancer

Статический калькулятор шансов получения ивентовых 5★ персонажей Honkai: Star Rail. Проект работает без сервера и собирается Vite в `dist/`.

## Запуск

```bash
npm install
npm run dev
npm run build
npm run preview
```

Расчёт выполняется в Web Worker методом Монте-Карло на 100 000 прогонов с фиксированным seed для каждого прогона. История (до 50 записей) хранится в IndexedDB, последние параметры — в localStorage. Стиль использует глубокий navy-фон, золотой и бирюзовый акценты; графики реализованы лёгкой CSS-инфографикой без внешней библиотеки. Неугасаемый пепел намеренно исключён: пользователь сам конвертирует его в пропуска, затем указывает итоговое количество ивентовых или стандартных круток.

Модель pity явно описана в блоке «Как мы считаем»: 5★ имеют 0,6% до 73-й попытки, затем прибавляется 6 п.п. за попытку до гарантии на 90-й; 4★ усиливаются с 8-й попытки и гарантируются на 10-й. Ивентовый pity изолирован от стандартного баннера. Заработанный звёздный свет учитывается рекурсивно. Результат является статистической оценкой, а не гарантией. Основные вероятности 0,6% / 5,1%, жёсткие гарантии, 50/50 и перенос между баннерами сверялись со страницами Warp и Character Event Warp в Honkai: Star Rail Wiki.
